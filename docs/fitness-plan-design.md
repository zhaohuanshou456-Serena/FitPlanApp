# 健身计划设计 · 主方案（已锁定：U/L 轮换版 A/B/C/D）

> 目标：减脂 / 保持肌肉（减脂期保肌优先）
> 频次：每周 4 练，具体日不固定 → 采用 A/B/C/D 循环轮换，练够一轮=一周期
> 时长：每节 60–75 分钟（含热身）
> 水平：初–中，偏安全稳妥；器械全（自由重量 + 器械）
> 手段：复合动作为主 + 器械兜底，渐进加重
>
> ✅ 已由用户选择为**主方案**；四分化版见 fitness-plan-4day.md（备选，保留）。

## 关于肩背每周量（回应关切）
完整一轮（1 周 4 练 = A+B+C+D）内：
- 背 ≈ 13–14 组（高位下拉+坐姿划船+引体+单臂划船），充足；
- 肩·中束直接 3 组、后束 3 组 → 稍偏低，故在 C 节补一节「反向蝴蝶机(后束)」并把侧平举安排保留在两个上肢日，让前/中/后束都有覆盖。

## 轮换规则
每次训练执行「下一节」：A → B → C → D → A …
每周争取完成 4 节（= 一轮）。某节状态与当前进度由 App 记录。

## 每节通用热身
- 动态热身 5–8 min（快走/单车 + 肩绕环、髋/膝活动）
- 每个复合动作先用轻重量 1–2 组热身组，不算入正式组

## 组 / 次 / 休息总览
- 主要复合动作：4 组 × 8–10 次，组间 90–120 s
- 辅助动作：3 组 × 10–15 次，组间 60–90 s
- 次数组用「下限起步，够到上限再加」的渐进加重（见下方规则）

## 渐进加重规则（App 建议逻辑）
以「每个动作当前重量」为基准：
- 若该动作**主项的任一正式组**能完成**目标次数的上限**（例如 10–12 做到 12 次），且动作标准：
  → 下次建议 **+2.5kg**（哑铃类 +1–2kg）。
- 若还差较远（做到 ≤ 中间值）：保持重量，优先把次数往上提。
- 若连续 2 次连下限都做不到或动作变形：建议 **−5% 或降一档**，回归标准。
- 每个动作的「当前重量 / 建议」由 App 按最近完成记录自动给出，执行时可直接确认或手动覆盖。

## 减脂配合提醒（非本方案主体）
- 力量计划之上，减脂主要靠热量缺口；建议每周额外 1–2 次 20–30 min 中低强度有氧，或靠日常步数。
- 动作全程重标准姿势、轻到中等节奏，优先安全。

## 待确认 / 可调点
- Session A/C、B/D 的动作是否贴合你常用器械与偏好
- 次数区间（想更偏力量可把主项降到 5–8）
- 是否要把核心/腹肌从 A 的收尾拆出来另加
